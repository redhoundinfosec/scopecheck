# Workflow Examples

## Pre-scan Validation

Validate your target list before running any scan.

```bash
# Generate targets from nmap host discovery
nmap -sn 192.168.1.0/24 -oG - | awk '/Up/{print $2}' > live-hosts.txt

# Validate against scope
scopecheck validate --file live-hosts.txt
if [ $? -ne 0 ]; then
    echo "ABORT: Out-of-scope hosts detected. Review before proceeding."
    exit 1
fi

# Safe to scan
nmap -sV -p- -iL live-hosts.txt
```

## Automated Pipeline Gate

Use scopecheck as a gate in automated testing pipelines.

```bash
#!/bin/bash
set -e

# Validate scope before any action
scopecheck validate -q --file targets.txt --format json > scope-result.json
EXIT=$?
if [ $EXIT -ne 0 ]; then
    echo "Scope validation failed. See scope-result.json for details."
    cat scope-result.json | jq '.results[] | select(.status != "in_scope")'
    exit 1
fi

echo "All targets validated. Proceeding with assessment."
```

## Multiple Scope Files

Maintain separate scope files for different engagement phases.

```bash
# External assessment
scopecheck validate --scope external-scope.yaml --file external-targets.txt

# Internal assessment
scopecheck validate --scope internal-scope.yaml --file internal-targets.txt
```

## Audit Trail for Reports

Export the audit log after an engagement for inclusion in reports.

```bash
# During engagement, all checks are logged automatically

# After engagement, export for the report
scopecheck audit --format json > audit-trail.json

# Or view recent checks
scopecheck audit --last 50
```

## Piping from Tools

Validate targets generated by other tools.

```bash
# From subfinder
subfinder -d acme.com -silent | scopecheck validate --stdin

# From masscan
masscan 192.168.1.0/24 -p80,443 --rate 1000 | awk '{print $6}' | scopecheck validate --stdin

# From a custom script
python generate_targets.py | scopecheck validate --stdin --format json
```

## Quick Single-Target Check

Verify a single target before manual testing.

```bash
# Quick check before SSH/RDP
scopecheck validate 10.0.0.50 && ssh admin@10.0.0.50

# Quiet mode — just check the exit code
scopecheck validate -q 10.0.0.50
echo $?  # 0 = in scope, 1 = not in scope
```
